# Death Rewind 2.1.0 功能测试指南

## 测试环境要求
- Minecraft 26.1/26.1.1/26.1.2
- Fabric Loader 0.18.4+
- Fabric API 0.144.0+
- MineBackup 3.1.0+（推荐 3.3.0 以验证欢迎消息不冲突）
- FolderRewind 主程序及 Minecraft 扩展
- Death Rewind 2.1.0

## 测试场景

### 1. 玩家进入时的状态显示

**测试步骤**：
1. 确保配置文件 `config/death-rewind.json` 中 `enabled: true`, `intervalMinutes: 5`
2. 启动单人世界
3. 观察聊天消息

**预期结果**：
- 先显示 MineBackup 的欢迎消息（如果安装了 MineBackup 3.3.0）
- 约 2 秒后显示 Death Rewind 消息：
  ```
  Death Rewind：每 5 分钟创建回溯点（下次还剩 5 分钟） [暂停] [配置]
  ```
- 三个元素都可以点击并有悬停提示

### 2. 暂停和恢复功能

**测试步骤**：
1. 在游戏中点击 `[暂停]` 按钮，或执行 `/dr pause`
2. 观察反馈消息
3. 退出并重新进入世界
4. 观察欢迎消息
5. 点击 `[恢复]` 按钮，或执行 `/dr resume`

**预期结果**：
- 暂停后显示：`Death Rewind 回溯点创建已暂停。`
- 重新进入时显示：`Death Rewind：回溯点创建已暂停 [恢复] [配置]`
- 暂停期间不会创建定时检查点
- 死亡界面的回溯按钮仍然可用（暂停只影响定时创建）
- 恢复后显示：`Death Rewind 回溯点创建已恢复。`

### 3. 状态查询

**测试步骤**：
1. 执行 `/dr status`
2. 等待几分钟后再次执行

**预期结果**：
- 显示：`Death Rewind：运行中 | 间隔：5 分钟 | 已过：X 分钟 | 剩余：Y 分钟`
- 已过时间应该递增
- 剩余时间应该递减
- 暂停状态下显示：`Death Rewind：已暂停 | ...`

### 4. 动态调整间隔

**测试步骤**：
1. 等待检查点计时推进（例如已过 3 分钟）
2. 执行 `/dr interval 10`
3. 立即执行 `/dr status`
4. 等待 10 分钟观察是否创建检查点

**预期结果**：
- 显示：`Death Rewind 间隔已更改为 10 分钟，计时器已重置。`
- 状态显示间隔变为 10 分钟，已过时间重置为 0
- 10 分钟后（而不是原来的 2 分钟后）创建检查点

### 5. 配置按钮

**测试步骤**：
1. 点击欢迎消息或状态消息中的 `[配置]` 按钮

**预期结果**：
- 聊天输入框中自动填入：`/dr interval `（末尾有空格）
- 可以直接输入数字并回车

### 6. 多存档切换

**测试步骤**：
1. 在存档 A 中执行 `/dr pause`
2. 退出到主菜单
3. 进入存档 B（未暂停）
4. 观察欢迎消息
5. 返回存档 A
6. 观察欢迎消息

**预期结果**：
- 存档 B 显示正常运行状态
- 返回存档 A 仍然显示暂停状态（会话级保持）

### 7. 权限测试（多人游戏）

**测试步骤**：
1. 在 LAN 或专用服务器上测试
2. 以非 OP 玩家身份尝试执行 `/dr status`
3. 给予玩家 OP 等级 2
4. 再次尝试

**预期结果**：
- 非 OP 玩家无法看到或执行 `/dr` 命令
- OP 等级 2+ 可以正常使用

### 8. 与 MineBackup 自动备份共存

**测试步骤**：
1. 启用 MineBackup 的 `/mb auto start 3 backup`
2. Death Rewind 设置为 5 分钟间隔
3. 观察两者是否正常工作

**预期结果**：
- 两条欢迎消息独立显示（MineBackup 先，DR 后 2 秒）
- 两个系统的定时器独立运行
- 如果时间接近，MineBackup 的操作门会序列化请求
- 两者都能正常创建备份

### 9. 死亡界面交互

**测试步骤**：
1. 启用 Death Rewind 并运行
2. 等待几分钟（但不到检查点间隔）
3. 死亡并打开死亡界面

**预期结果**：
- 死亡界面打开时，定时器暂停推进
- 可以正常使用回溯按钮
- 关闭死亡界面后，定时器继续推进

## 边界情况测试

### 间隔边界值
- `/dr interval 1` - 应该成功（最小值）
- `/dr interval 1440` - 应该成功（最大值 = 24 小时）
- `/dr interval 0` - 应该失败并提示范围
- `/dr interval 1441` - 应该失败并提示范围

### 重复操作
- 连续执行两次 `/dr pause` - 第二次应提示"已处于暂停状态"
- 连续执行两次 `/dr resume` - 第二次应提示"已在运行中"

### 未启用 DR 时
1. 修改配置文件 `enabled: false`
2. 重启世界
3. 执行 `/dr status`

**预期结果**：
- 不显示欢迎消息
- 命令提示"Death Rewind 在此世界中未启用。"

## 国际化测试

切换语言设置到英语后测试：
- 欢迎消息应显示英文
- 命令反馈应显示英文
- 按钮悬停提示应显示英文

## 性能检查

- 欢迎消息延迟不应影响玩家加载
- 命令执行应立即响应
- 暂停/恢复不应导致卡顿
